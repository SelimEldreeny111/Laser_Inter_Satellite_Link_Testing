# GUI branding assets

The EgSA images in this directory are local offline copies of artwork served by
the official Egyptian Space Agency website:

- `egsa_icon.png`: `https://egsa.gov.eg/assets/EgsaLogo-3.png`
- `egsa_logo.png`: `https://egsa.gov.eg/assets/Nav-EgsaLogo%20-%20With%20Iso.png`

Retrieved on 2026-08-09. The GUI uses `egsa_icon.png` for its header and window
icon. These files are branding assets, not generated substitutes.
